## GitHub profile / GitHub CV

**RepsCounter — In Development** | Swift, UIKit, AVFoundation, Vision, Core Data, XCTest

An iOS computer-vision portfolio project for on-device human pose tracking and automatic exercise repetition counting. The initial codebase implements a rear-camera pipeline, 2D joint estimation, a squat-counting state machine and a workout-session UI. Real-device verification is in progress.

## LinkedIn project entry

**RepsCounter (In Development) — iOS Computer Vision Project**

Developing a native iOS app that analyzes live camera frames locally using AVFoundation and Vision. The initial implementation focuses on joint-angle estimation and deterministic squat repetition counting, with a UIKit interface and Core Data workout history. The project demonstrates separation of camera, inference, domain logic and UI, with unit tests for the counting algorithm. Hardware and accuracy testing are pending.
