# Следующие задачи RepsCounter

Статус: **In Development**. План по результатам [аудита от 24 октября 2026 года](TECHNICAL_AUDIT.md). Это список предлагаемых работ; реализация следующего этапа не начата.

| Порядок | Приоритет | Задача | Критерий готовности |
|---|---|---|---|
| 1 | P1 | Перейти на программный `UIScene` lifecycle — A01 | UIKit/MVVM и iOS 17 сохранены; приложение и XCTest запускаются с текущим SDK на iOS 27; проверен запуск на нижней поддерживаемой версии |
| 2 | P2 | Сделать завершение и сохранение надёжными — A03, A04, A09 | Явный результат сохранения, повтор без потери сводки/дубликатов; история не показывает failed insert; контекст изолирован; XCTest на успех, отказ и повтор |
| 3 | P2 | Исправить паузу, отдых и итоговое время — A05, A10 | Управляемое время; остаток отдыха заморожен на паузе; незавершённый цикл не переносится через паузу или прерывание тренировки; итоговое время неизменно; XCTest на фазы, отдых и finish |
| 4 | P2 | Изолировать состояние камеры и управлять её жизненным циклом — A02, A06 | Нет strict concurrency diagnostics; stop/start и отмена согласованы; нет позднего запуска после finish; проверены разрешения, возврат из Settings, фон и прерывания на iPhone |
| 5 | P2 | Довести Dynamic Type и доступность — A07 | Шрифты обновляются во время работы; счётчик масштабируется; кнопки и текст доступны на маленьком iPhone и AX1–AX5; выполнена проверка VoiceOver |
| 6 | P2 | Укрепить границы DI и тесты — A08 | Узкий контракт хранилища и источник времени без смены стека; тесты ViewModel/PoseAnalyzer и крайних случаев confidence, пропусков, aspect ratio и смены ноги; существующие тесты сохранены |
| 7 | P2 | Проверить весь camera → Vision → overlay → counter на устройстве | Rear camera/portrait проверены с crop/aspect fill; размеченные локальные клипы дают измеримые false positives/negatives; проведена 10-минутная проверка памяти, нагрева и задержки; точность не заявляется до измерений |
| 8 | P3 | Устранить замечания истории, диагностики и оформления — A10, A11 | Ошибки истории показываются после появления; ошибки Vision различимы без сохранения кадров; таймер отменяется; согласована семантика sets; убран deprecated API; проверена русская локализация; подготовлены launch screen/icon и план миграции данных |

Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Новые упражнения, планы, графики и расширение UI остаются за пределами этого этапа. Работы по таблице начинать после согласования пользователем.
