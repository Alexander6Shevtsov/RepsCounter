Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Runtime iOS 17 и физический iPhone пока недоступны для проверки. Автоматическая пауза при уходе в фон и прерываниях камеры относится к A06 и в этап №4 не входит.

Новые упражнения, планы, графики и расширение UI остаются за пределами этого этапа. После PR по A05/A10 остановиться; merge и остальные работы по таблице требуют отдельного согласования пользователем.
