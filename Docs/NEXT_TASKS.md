Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Runtime iOS 17 недоступен в текущей среде. Пользователь сообщил о пропусках приседаний на физическом iPhone 15 Pro при корректном скелете; это наблюдение не подтверждает точность нового кода. Физические испытания PR №7 остаются открытыми. Автоматическая пауза объединена через PR №4; переключение камер сохраняет её семантику. Mock-тесты не подтверждают системные прерывания, Vision, задержку остановки SDK или отсутствие аппаратных гонок. При диагностической компиляции Swift 6 остаётся warning неизменённого `WorkoutPersistenceTests.swift:255` о mutable capture. PR №6 использует compatibility helper для device-aware portrait на iOS 17–26; его deprecation warning обоснован в документе камеры, replacement доступен только с iOS 27.

Новые упражнения, планы, графики и расширение production UI остаются за пределами этого этапа. После создания исследовательского PR остановиться для code review без merge. Внедрение полного 3D-счётчика в production, изменение порогов и последующие доработки требуют отдельного согласования. Порог непрерывности рабочего 2D 250 мс сохраняется; влияние дополнительной нагрузки нужно измерить на iPhone.
