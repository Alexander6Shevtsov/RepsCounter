Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Runtime iOS 17 и физический iPhone не проверены. Автоматическая пауза объединена через PR №4; переключение камер сохраняет её семантику. Mock-тесты не подтверждают системные прерывания, Vision, задержку остановки SDK или отсутствие аппаратных гонок. При диагностической компиляции Swift 6 остаётся warning неизменённого `WorkoutPersistenceTests.swift:255` о mutable capture. PR №6 использует один явно помеченный compatibility helper для device-aware portrait на iOS 17–26; его deprecation warning обоснован в документе камеры, replacement доступен только с iOS 27.

Новые упражнения, планы, графики и расширение UI остаются за пределами этого этапа. После PR по переключению камер остановиться для ревью. Merge, аппаратные доработки и остальные работы по таблице требуют отдельного согласования пользователем.
