Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Runtime iOS 17 и физический iPhone не проверены. Автоматическая пауза реализована на этапе №5; mock-тесты не подтверждают фактические системные уведомления на устройстве, работу Vision, задержку остановки SDK или отсутствие аппаратных гонок. В Swift 6 остаётся warning неизменённого `WorkoutPersistenceTests.swift:248` о mutable capture; deprecated `imageEdgeInsets` — A11. Новых предупреждений изменённые camera-компоненты и тесты не добавляют.

Новые упражнения, планы, графики и расширение UI остаются за пределами этого этапа. После PR по A02/A06 остановиться для ревью. Merge, аппаратные доработки и остальные работы по таблице требуют отдельного согласования пользователем.
