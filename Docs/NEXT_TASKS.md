|---|---|---|---|
| 1 | P1 | A01: программный `UIScene` lifecycle — объединено в main через PR №1 | Регрессионные SceneLifecycleTests сохраняются в полном наборе. Runtime iOS 17 недоступен; запуск на минимальной версии остаётся непроверенным |

| 5 | P2 | Довести Dynamic Type и доступность — A07 | Шрифты обновляются во время работы; счётчик масштабируется; кнопки и текст доступны на маленьком iPhone и AX1–AX5; выполнена проверка VoiceOver |
| 6 | P2 | Укрепить границы DI и тесты — A08 | Узкий контракт хранилища и источник времени без смены стека; тесты ViewModel/PoseAnalyzer и крайних случаев confidence, пропусков, aspect ratio и смены ноги; существующие тесты сохранены |
| 7 | P2 | Проверить весь camera → Vision → overlay → counter на устройстве | Rear camera/portrait проверены с crop/aspect fill; размеченные локальные клипы дают измеримые false positives/negatives; проведена 10-минутная проверка памяти, нагрева и задержки; точность не заявляется до измерений |

Проверки для согласованного исправления: Debug/Release, полный существующий XCTest, новые регрессионные XCTest, запуск на iOS 17 и актуальной iOS, аппаратная проверка камеры. Версию Xcode для команды и CI нужно зафиксировать отдельно: исходная документация называет Xcode 26, аудит фактически выполнен в Xcode 27.1.

Новые упражнения, планы, графики и расширение UI остаются за пределами этого этапа. После PR по A03/A04/A09 остановиться; merge и остальные работы по таблице требуют отдельного согласования пользователем.
