## Финальная визуальная доработка

По сообщению пользователя, исходный интерфейс PR №10, скелет, счётчик, завершение и история проверены на физическом iPhone 15 Pro. Ниже — последующая доработка компактности и затемнения; её восприятие на живом видео требует повторной оценки на устройстве.

- Колонка показателей занимает 50% ширины контента вместо 64%; внутренние отступы уменьшены с 12 до 8 pt по вертикали и до 10 pt по горизонтали. Декоративные пиктограммы — 18 pt вместо 22, скругления карточек — 16 вместо 20.
- На iPhone 15 Pro / стандартном Dynamic Type боковые карточки имеют размер 176,7×52,7 pt вместо 226×62,7: площадь каждой меньше на 34,3%. Суммарная прямоугольная площадь пяти карточек в активном состоянии уменьшена на 28,0%. Это измерение UI-рамок, а не оценка распознавания или универсального перекрытия тела.
- Время и общий результат размещаются ближе к нижним кнопкам. Гибкий отступ с низким приоритетом оставляет середину кадра свободной, а при недостатке высоты схлопывается. При крупных шрифтах сохраняется вертикальная прокрутка.
- Альфа чёрного градиента сверху/в середине/снизу изменена с 0,68/0,52/0,72 на 0,30/0,06/0,34. Это прозрачность слоя Presentation, не изменение экспозиции, камеры или обработки кадров.
- Крупный счётчик, белые подписи и заголовок получили локальную тень. Размеры и масштабирование текста, синий акцент, blur-поверхности и доступность основных действий сохранены.

## Слой Presentation

- `WorkoutDashboardView` только отображает переданные состояния и вызывает замыкания действий. В нём нет таймера, распознавания, доступа к Core Data или управления камерой.
- `WorkoutAppearance` задаёт общие цвета, шрифты и тёмные blur-поверхности `UIVisualEffectView` на MainActor.
- `WorkoutBackdropView` добавляет неинтерактивный градиент под скелетом для читаемости текста поверх видео.
- `WorkoutViewController` сохраняет существующий coordinator, callback позы, настройки preview, обработчики действий и очередь сообщений сохранения. Метрики переданы отдельному представлению.
- `WorkoutHistoryViewController` показывает реальные записи в карточках автоматической высоты. Пустая история и ошибка различаются; ошибка загрузки отображается встроенным состоянием вместо попытки показать alert ещё в `viewDidLoad`.
- `PoseOverlayView` меняет только толщину/скругление линий и тень, без изменения суставов, confidence или преобразования координат.

При фактическом запуске на свежем iPhone 15 Pro Simulator / iOS 18.6 обнаружена уменьшенная область приложения с чёрными полями. В исходном plist отсутствовала конфигурация launch screen. Добавлен только пустой словарь `UILaunchScreen`, предусмотренный [документацией Apple](https://developer.apple.com/documentation/bundleresources/information-property-list/uilaunchscreen) для запуска без Storyboard. Это необходимое изменение метаданных для полноэкранной компоновки; регистрация сцены, portrait и минимальная iOS не изменяются. XCTest проверяет собранный plist.

## Состояния и доступность

Подготовка камеры, системный запрос доступа, отказ, временная недоступность, переключение и повтор отражаются в статусе и поясняющей карточке. Системный permission prompt не заменяется собственным экраном.

Во время отдыха показан действительный остаток; пауза сохраняет его на экране. Успех сохранения появляется только при `.saved`; `.failed` оставляет кнопку «Повторить». UUID, итог, повторное сохранение и поведение существующих alert сохранены. История продолжает использовать внедрённый `WorkoutStoring`, не создаёт записей и не переупорядочивает их.

Текст масштабируется через Dynamic Type. На accessibility-размерах карточки занимают полную ширину, сводка и кнопки выстраиваются вертикально, дублирующий заголовок «Тренировка» скрывается. Пиктограммы ограничены размерами кнопок, touch target — минимум 44 pt. Камера и скелет не находятся внутри scroll view.

Верхние действия и пауза/завершение доступны без прокрутки. Метрики и пояснения при недостаточной высоте прокручиваются вертикально; горизонтальной прокрутки нет. На максимальном размере текста нельзя одновременно показать все карточки без уменьшения шрифта, поэтому данные остаются доступными в теле экрана с прокруткой.

Debug-панель из `main` занимает пространство тела между toolbar и кнопками, временно скрывая карточки. Выключение возвращает их, не меняя тренировку. Сбор диагностических значений и обработка поз не изменены. Экспериментальный интерфейс 3D отсутствует; Release исключает прежнюю Debug-панель.

| Release plist и бинарный файл | iOS 17.0, launch screen, нет Storyboard; Debug identifiers и Vision 3D request отсутствуют, рабочий Vision 2D присутствует |

Для Release XCTest включён `ENABLE_TESTABILITY=YES` только в команде сборки. Отдельный Release для iPhone собран с обычными настройками проекта. После уточнения lifecycle тестовых окон итоговые прогоны не содержат предупреждений `Unbalanced calls to begin/end appearance transitions`. Регрессии камеры, UIScene, Core Data, миграции, UUID-повтора и таймеров входят в полный набор.

UIKit-тесты используют синтетические состояния и проверяют отображение; они не подтверждают точность Vision или работу физической камеры. В PR добавлено 16 XCTest: десять для dashboard, пять для истории и один для launch screen; три из них добавлены при финальной доработке. Проверяются реальные значения, маршрутизация действий, подготовка/отказ/переключение камеры, пауза/отдых, сохранение/ошибка/повтор, порядок истории и ошибка хранилища. Две матрицы компоновки покрывают 375×667, 393×852 и 430×932 pt × все 12 категорий Dynamic Type, с проверкой реального роста шрифта, размеров текста и пиктограмм, отсутствия горизонтального переполнения и перекрытия кнопок. Существующая Debug-layout регрессия проверяет видимые элементы после открытия панели.

При первоначальной реализации PR №10 вручную на временном iPhone 15 Pro / iOS 18.6 Simulator выполнены запуск Release, открытие и закрытие пустой истории, завершение нулевой тестовой тренировки, показ успешного сохранения и открытие её реальной записи в Core Data. После финальной доработки отдельно повторены запуск Release и отказ в системном разрешении камеры; проверена доступность основных кнопок. Обновлён реальный скриншот тренировки в README: он показывает состояние отказа и нулевые значения. Снимок пустой истории сохранён, её код этой доработкой не менялся. Камера Simulator недоступна, поэтому движения и точность не проверялись. `Concept.png` подписан отдельно как концепт; сравнительные UIKit-attachments содержат синтетические фон, геометрию и значения.

Разработчик не запускал финальную доработку на физическом iPhone; отзыв пользователя о базовом интерфейсе указан выше отдельно. Runtime iOS 17 отсутствует; доступность iOS 17 проверяется сборкой с прежним deployment target, но запуск на этой версии не подтверждён. Остались прежние предупреждения legacy portrait compatibility и mutable capture в неизменённом Core Data XCTest при диагностике Swift 6; служебное сообщение AppIntents metadata не относится к UI. Новых предупреждений компилятора в изменённых компонентах нет.
